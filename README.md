# AI Dictaphone (Умный AI Диктофон)

Нативное мобильное приложение для Android (Kotlin, Jetpack Compose, Material 3), портированное и переписанное из проекта `Ai_dictaphone_test_hack`.

Приложение объединяет функции профессионального диктофона с локальным искусственным интеллектом для распознавания речи (Whisper) и глубокого семантического анализа стенограмм (Llama).

---

## 🚀 Основные возможности

### 1. Запись звука и интерактивная визуализация
- Запись голоса в реальном времени с поддержкой паузы, возобновления и отмены.
- Живая пульсирующая волновая диаграмма амплитуды звука (`AudioRecorderManager`).
- Точный таймер записи с отображением миллисекунд.
- Назначение пользовательских названий и автоматическое присвоение тегов.

### 2. Распознавание речи (`WhisperEngine` — порт `WhisperBase`)
- Автоматическая транскрипция аудиофайлов на русском и английском языках.
- Сегментация речи с точными временными метками `[00:00 - 00:04]`.
- Настройка параметров поиска:
  - `language`: Язык распознавания (`ru`, `en`, `auto`).
  - `threads`: Количество вычислительных потоков CPU.
  - `beam_size`: Ширина луча Beam Search.
  - `temperature`: Температура генерации токенов.
  - `translate`: Автоматический перевод на английский язык.
  - `timestamps`: Включение/отключение временных меток.
  - `no_context`: Изоляция контекста между сегментами.

### 3. Анализ текста и генерация (`LlamaEngine` — порт `LlamaBase`)
- **Краткая выжимка (Executive Summary):** Автоматическое выделение главного смысла встречи или лекции.
- **Поручения и задачи (Action Items):** Извлечение списка задач с чекбоксами и ответственными лицами.
- **Протокол встречи:** Форматированный официальный протокол совещания (тема, дата, участники, повестка, решения).
- **Очистка текста:** Удаление слов-паразитов и исправление пунктуации.
- **Интерактивный чат с Llama:** Ответы на любые вопросы по содержанию аудиозаписи с учетом контекста стенограммы.
- Настройка параметров Llama:
  - `context_size`: Размер контекстного окна (1024, 2048, 4096 токенов).
  - `threads`: Потоки CPU.
  - `max_tokens`: Лимит генерации токенов.
  - `temperature`: Степень креативности ответов.
  - `topP` / `topK`: Параметры вероятностной выборки токенов.
  - `system_prompt`: Пользовательская системная инструкция.

### 4. Воспроизведение звука (`AudioPlayerManager`)
- Полнофункциональный аудиоплеер с ползунком перемотки и таймлайном.
- Перемотка на ±5 секунд.
- Регулировка скорости воспроизведения (0.75x, 1.0x, 1.25x, 1.5x, 2.0x).
- Синхронизация подсветки текущего фрагмента стенограммы во время прослушивания.

### 5. Управление библиотекой записей
- Полнотекстовый поиск по названиям и стенограммам.
- Фильтрация по категориям и тегам (#Встреча, #Обучение, #Интервью, #AI, #Заметка).
- Добавление в избранное, удаление, быстрое копирование текста в буфер обмена.

## 🛠 Архитектура

- **UI:** Jetpack Compose, Material 3, адаптивная верстка, edge-to-edge.
- **Архитектура:** MVVM (Model-View-ViewModel) + Clean Architecture.
- **Язык:** Kotlin 2.x, Coroutines, StateFlow.
- **Целевая платформа:** Android 7.0+ (API 24+), Compile SDK 36.
